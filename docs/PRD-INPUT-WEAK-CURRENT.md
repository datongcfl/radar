## 三、写 PRD 前必须由人拍板的剩余风险（非 `strong` 单元）

虽然全包已做到 **`0 none`**，但仍有两类缺口需要人工业务确认，不能当成“已完全证实”：
1. **8 个仍停在 `mention` 的单元**（`M04` 询价与产品库、`M05` 预估成本与容量、`M09` 施工与进度、`M12` 发票与收付款、`S05` 视频监控、`S06` 门禁一卡通、`S19` 会议/多功能厅、`S20` 背景音乐）：多为缺原文 quote 或仅抓到短描述。
2. **11 个单源 `evidence` 单元**（`M07`, `M10`, `M11`, `S07`, `S08`, `S15`, `S16`, `S17`, `S18`, `S21`, `S23`）：特别是弱电特有的**“工程项目编码、点位图纸变更签证、分包结算发票勾稽”**，开源世界本就稀缺，需要结合你的内部项目经验拍板。
